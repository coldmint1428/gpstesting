1. Who does what

Every person in an event has a role. Your role is shown next to the event name (for example Planner · Test group A: Admin, IC).

RoleWhat they do
RootCreated the event. Can do everything a planner can, and manage the event itself.
PlannerBuilds the run sheet, zones and groups; starts and runs the show; watches every group on the Ops / Live map page; can message everyone at once.
MarshalHelps on the ground: sees the groups, can mark a group in position (e.g. heard on the radio) and report delays for it.
Group adminLooks after one group: adds its people.
IC (in charge)The person whose phone shares the group's location. Gets "Your next move" with a countdown, and can tell the planners about a delay or say "We're in position".
MemberBelongs to a group; sees where the group must be next.
The app supports the radio. It does not replace it. Keep using your usual radio channel and call signs. The app adds a shared live picture and timings, so everyone stays on the same page and fewer radio calls are needed.
Website

2. My events

After you sign in, My events lists every event you belong to with your role. Click an event to open it.

  1. Join with a code: type the 6-character code your planner sent (e.g. K7Q2XM) and press Join.
  2. Create an event: press Create an event. You become the event's Root.
  3. Simulation event: for practice, type a name and press Create. It has virtual groups and is clearly labelled SIMULATION.

3. Create an event (4 steps)

  1. Details: name (required), description, venue, start and end time (required). Press Next.
  2. People: add the people who will take part.
  3. Groups: make the groups and put people in them.
  4. Preview: check everything, then create the event. Start over clears the wizard; Cancel leaves it.
Website

4. Event page & live map

The event page has a tab for each job: Live map, Run sheet, Zones, Members, Invite, Playback. The box at the top always shows whether the event is live.

Start the event

  1. Press Start event now, or Schedule… to pick a start and end time. Pick a Ready run sheet version to run the show with it.
  2. Once the event is live, each IC presses Share my location. Their group's marker appears on the live map within about 15 seconds.
  3. My GPS details shows your own last reading and its accuracy.

Group statuses (map labels, Needs attention list)

StatusMeaning
On trackWill reach its zone in time.
At riskWill only just make it: the label shows the seconds to spare.
LateWill not make it in time: the label shows by how much (e.g. +1:30).
○ Not sharing yetNone of the group's ICs has pressed Share in this session.
◌ No signalThe ICs were sharing but nothing has been heard for 2 minutes.
Arrived / Arrived lateThe group is inside its zone (or an IC / marshal said "in position").

5. Run sheet

The run sheet is the show's running order. It answers two questions: what happens when (the cues) and which group must be where, by when (the movements). During the show, the app counts down to each cue and tells every group when to leave.

WordWhat it meansExample
CueOne item of the show, with a start time and a length.C01 Pre-show set up, 18:00:00, 1:00
SectionA heading that groups cues together.PRE-SHOW, PARADE
MovementA group must be inside a zone by a certain time (usually when a cue starts).M01 Test group A → TREES by the time C01 starts
Zone codeThe short name of a zone, drawn on the Zones page. Movements point to it.TREES, FORMATION_A
VersionOne complete copy of the run sheet. Keep several (rehearsal, show day) and pick one when you start.Rehearsal 1, Show day
Do this first: draw the zones (section 6) and create the groups (section 7). A movement needs both a group and a zone to point to.

Step 1: pick or make a version

Every version is in one of three states, shown in the version list:

StateWhat you can do
✏️ DraftBeing written. Edit freely. It cannot be picked to run a show yet.
✅ ReadyChecked with no problems. It can be picked when the event starts. Editing it makes it a draft again until it is checked.
🔒 UsedIt has run in a show, so it is kept exactly as it was (for playback and records). To change it, press Duplicate and edit the copy.
  • New version starts an empty draft. Duplicate copies the selected version, with all its cues and movements, as a new draft.
  • Rename changes the version's name; Delete removes a version that has never been used.
Website · Run sheet

Step 2: add the cues

Press Add cue (top right of the Cues card), or click any cue in the table to edit it. The editor opens right under that cue.

FieldWhat to enter
Cue nameWhat happens, e.g. "Parade & Ceremony".
Section / CodeSection groups cues under a heading. Code is filled in for you (C01, C02…); change it only to match your own paper run sheet.
StartThe planned start time. Tick After midnight (+1 day) for cues past 00:00.
Length (m:ss)How long it lasts, e.g. 2:30.
TypeNormal: moves later if the show runs late. Flexible (can shorten): can be cut by up to the "Can shorten by" time to win back a delay. ⚓ Anchor (fixed time): always starts at its time, e.g. a fly-past or a TV live link.
How it startsAuto (on time): starts by itself at its time. Auto when groups are ready: starts at its time only once the groups it needs have arrived. Manual (waits for GO): waits until a planner presses GO.
Area / Department / NotesFor reference only.

Press Save cue. When editing an existing cue you can also move it ↑ Up / ↓ Down, Add cue after, or Delete it.

Website · Run sheet

Step 3: add the movements

Press Add movement on the Movements card. Each movement says: this group must be inside this zone by this time.

FieldWhat to choose
Who movesOne group, or A whole category (every group with that category in Members → Group details, e.g. all "Contingent" groups). For a category you can add exceptions: a group that goes elsewhere or skips it.
Where toThe zone, by its code. "Not decided yet" is allowed in a draft, but the check flags it.
By whenWhen a cue starts, when a cue ends, or at a fixed time. Choose the cue next to it.
Arrive early byHow long before that time the group should already be there (e.g. 2:00).
Counts as arrived whenHow many of the group's ICs must be inside (blank = all of them), and for how long (default 0:20), so a phone passing through does not count.
Amber when spare <When the group turns At risk: e.g. 0:30 means amber once it has less than 30 s to spare.
How they travelOn foot uses walking routes for the ETA. Vehicle and Fixed route are kept with the plan but timed like walking for now.

Press Add movement to save. The cue's row in the table then shows a chip such as Test group A → TREES; click it to jump to the movement.

Step 4: check it and mark it Ready

  1. Press Check & mark ready. The check reads the whole version and lists what would go wrong in the show, for example: a cue that starts before the one above it ends; an ⚓ anchor that the cue before it runs into; a cue with no length; a movement with no zone or no cue; a zone that has become No-Go; a group sent to two zones at the same time; a group with no IC, so its arrival cannot be tracked.
  2. Problems appear in red (✗ must fix) or amber (! worth a look) next to the cue or movement. Fix them and check again.
  3. With no ✗ problems the version becomes ✅ Ready.

Step 5: run it

Press Start event now or Schedule… and pick the Ready version. From then on it is 🔒 Used.

Excel

  • Template downloads an empty Excel workbook with the right columns and an instructions sheet.
  • Import reads a filled workbook and saves it as a new draft version. If a row has a problem, it lists every problem by row number so you can fix the file and import again.
  • Export this version saves the selected version as an Excel file; importing that file again gives an identical copy.

6. Zones

Zones are the areas on the map that groups must reach (formation areas, holding areas, doors) or must stay out of (No-Go). Only the event's root and planners can change them; everyone else sees them on the live map.

TypeUsed for
ZoneA place a group must reach. Movements in the run sheet point to it.
No-GoA place groups must not enter. Entering it sends one alert to planners and marshals and a red banner to the IC.
Obstacle / Stage / EntranceShown on the map to help people find their way.

Overview

Website · Zones

Draw a new area

  1. Zoom the map to the place (scroll wheel or + / −).
  2. Press Draw areas. The hint at the top of the map says Click to add a point.
  3. Click each corner of the area in turn. You need at least 3 points; lines may not cross.
  4. Close the shape by clicking the first dot again, or press Finish.
  5. Type a Name (e.g. "Trees"), choose the Type, then press Save area. A code is made from the name (TREES).
  6. Press Done to stop drawing. Clear throws away the shape you are drawing; Esc does the same.

Change an area

  • Click the area on the map to select it. The hint says Drag a dot to move it, click a dot to remove it, click an edge to add one.
  • Drag inside the shape to move the whole area. Press Esc during a drag to put it back.
  • Copy then Paste makes a second area of the same shape next to it (with the next free code, e.g. TREES_2).
  • Undo ↶ and redo ↷ sit above the map (Ctrl+Z / Ctrl+Y). Undo only touches your own changes.
  • Delete or Backspace deletes the selected area after a "Delete …?" question.
Website · Zones

The list of areas

  • Name is what people read on the map. Renaming keeps the code, so the run sheet still finds it.
  • Code is what the run sheet uses. It must be unique in the event and is written in capitals (typing "form a" gives FORM_A).
  • Type can be changed at any time.
  • A zone that a run sheet movement still uses cannot be deleted. Change or delete that movement first.

Floor plans

  1. Press Add a floor plan and choose a picture (PNG or JPG), or copy a picture and press Paste a floor plan.
  2. Drag it into place over the map; drag a corner to resize it and the round knob to turn it. Areas can be drawn on top.
  3. Each floor plan has its own name and show / hide switch.
  4. The ring next to Storage shows how much of the 4 MB allowance is used. Pictures use almost all of it; areas take a few bytes each.
Working together: several planners can edit at once, one shape each. A shape someone else is editing shows their name and cannot be changed until they let go.

7. Members

  1. Create a group: pick its colour, type a name, press Add.
  2. Add a person: type a username, name or full email, choose a group, press Add.
  3. On each person's card: change their group, make them Group admin or IC, or Remove from event. The badge shows ● Sharing or Not sharing yet.
  4. Group details (category, code, sector, headcount, radio channel) are used by category movements and shown to ICs.

8. Invite

Send the code, the link (Copy, WhatsApp or Telegram) or let people scan the QR.

Playback

▶ Play replays a session on the map. Recordings stay online for 7 days; Download CSV keeps one longer, and Replay from a CSV file plays it back later.

9. Getting started on the phone

The phone app has the same events as the website, laid out for one hand: tabs at the bottom, one main action per screen, and sheets that slide up for extra choices.

My events

  • A live event shows at the top as a big card: tap Open live view.
  • Other events are listed by date, soonest first, with your role.
  • The orange + Join event button opens the join sheet.
  • Bottom tabs: Events, Phone (phone setup), Me.

Join an event

  1. Tap + Join event.
  2. Type the 6-character code and tap Join. Or open the invite link from WhatsApp or Telegram.

Phone setup (the Phone tab)

Before your first show, go through the steps on the Phone tab so Android does not pause the location sharing:

  • Location permission "Allow all the time".
  • Turn off Power saving while you share.
  • Allow notifications (Get ready / Leave now reminders).
You can skip a step with Skip for now and come back to it later.
Android phone app

Me

  • Location sharing tells you whether your phone is sharing now, and for which event. Tap Stop to stop.
  • Phone set-up opens the setup steps again.
  • Log out signs you out of the app.

10. Planner screens

Inside an event, the header shows the event name, your role and a red ● LIVE badge while the show runs. Planners, roots and marshals get these tabs: Ops, Map, Run sheet, People, More. Tap the back arrow to return to My events.

Ops

  • Before the show: Start event now or Schedule…, and Share my location once live.
  • During the show: the current cue, Needs attention (most urgent group first, with what to do), and your own group's next move if you are also an IC.
  • A red dot on the Ops tab means a group needs attention.

Map

Every group's marker with its status label, the zones, and the list of who is sharing and when they were last heard.

Android phone app

More

Tap More for the less frequent pages, in a sheet that slides up:

  • Zones: areas, doors and No-Go areas (same as the website).
  • Invite: join code, link and QR, with WhatsApp / Telegram buttons.
  • Playback: replay a past session.
  • Simulator (simulation events only).
  • Event info: details, and leave the event.

Tap outside the sheet or the ✕ to close it.

Android phone app

11. IC screens: your next move

ICs and members get the tabs Now, Map, Group, Info. (A planner who is also an IC sees the same card on Ops.)

Your next move

  • Where and by when: e.g. "Be inside trees (TREES) by 18:00:00".
  • Time left and distance, and Leave by: the latest time to set off.
  • The status chip (● On track) is what the planners see.
  • The small map shows you and the zone.

Tell planner: delayed

  1. Tap Tell planner: delayed. A sheet slides up.
  2. Tap a quick reason (Stuck at a gate, Crowd in the way, Waiting for our people, Route blocked) or type one.
  3. Tap Tell the planners. They see it at once on Ops. The button then shows "Planners told ✓" for a minute.

We're in position

Tap We're in position when the whole group is in place. It counts at once, without waiting for GPS. You can undo it for 5 minutes.

Stop sharing

Tap Stop sharing when you are done (also on the Me tab).

Keep the app sharing for the whole show. If your phone is in Power saving or the location permission is not "All the time", Android may pause the sharing and planners will see No signal.

12. Message everyone

Send one message to many people at once: everyone in the event, every group, all ICs, the staff, one sector or one category. Each person gets a push and a banner on the event page that stays until they press Got it. You see how many have confirmed, and who has not, so you only need the radio for those.

When to use it: lightning or heavy rain, "hold in place", an evacuation, the wet weather plan, or "the show is running late". To talk to one group, use Message on that group in Needs attention instead.

Send a message

  1. Website: on the Live map page press Write a message. Phone: on the Ops tab press Write a message; the form slides up.
  2. Tap a quick message (⚡ Lightning: shelter, Hold in place, All clear: resume, Wet weather plan, Show running late, Evacuate), or type your own (up to 300 characters). You can change a quick message's words before sending.
  3. Choose Who gets it (table below).
  4. Tick Urgent for anything about safety: it shows in red. Lightning, Hold and Evacuate tick it for you.
  5. During a show, Lightning and Hold offer Also hold the show, and All clear offers Also resume the show: one press sends the message and holds (or resumes) the show.
  6. Press Send. A check says exactly how many people will get it ("Send to 124 people?"). Press Send again to confirm.
Who gets itWho that is
Everyone in the eventEvery person with any role, except you.
Every group's membersEveryone who is in a group.
ICs and group adminsThe people leading each group.
Planners and marshalsThe root, planners and marshals.
One sector… / One category…The members of the groups with that sector or category (set in Members → Group details). A sector also reaches the marshals of that sector.
Website + phone app · Message everyone

What people see

  • A push on their phone, even with the app closed. Tapping it opens the event.
  • A banner at the top of the event page (red if urgent), on every tab. Newer messages show on top.
  • Got it removes it, on all of that person's devices.

Check who has read it

  • Got it: 12 of 15 counts people who pressed Got it; seen by counts people who had it on screen.
  • Press Who has not for their names, group, whether they are the IC, and the group's radio channel. Radio only those.
  • Take down removes the banner from everyone's screen (e.g. after All clear). The message stays in your list as a record, and every message is in the show log for playback.

On the phone

The same form opens as a sheet from the Ops tab. Scroll inside the sheet to reach Send; tap outside it or ✕ to close without sending.

The radio stays the backup. A push can be delayed by a phone in Power saving or Do Not Disturb. Use "Who has not" to find those people and call them.

13. Help when something looks wrong

What you seeWhat to do
○ Not sharing yet on a groupNone of its ICs has pressed Share my location in this session. Ask the IC to open the event and press Share (the event must be live).
◌ No signal on a groupThe IC was sharing but nothing has arrived for 2 minutes. Check the IC's phone: is it in Power saving, out of signal, or did they stop sharing? Call them on the radio.
"Share my location" is greyed outThe event is not live yet. A planner must press Start event now (or wait for the scheduled start).
Marker appears only after ~15 sNormal: the first reading takes about 10-15 seconds after pressing Share. After that the status updates every few seconds.
Invite link says "localhost"The link was made on a test computer and only works there. Use the event code or the link from the public website.
A run sheet version cannot be editedIt has been used in a show (🔒 Used). Press duplicate it to make an editable copy.
A zone cannot be deletedThe run sheet still has a movement to it. Change or delete that movement first.
Blank or wrong page on the phoneTap the Events tab or the back arrow; any unknown address now returns to My events.
Remember: the radio stays the main way to talk during a show. Use the app to see where everyone is and how the timing looks, and to send quick updates (delayed, in position) that everyone can see.
